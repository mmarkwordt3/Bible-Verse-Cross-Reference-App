# Review-assistance data quality

`reports/greek-review-assistance-coverage.json` reports complete, partial, unavailable, ambiguous, unsupported, missing, and conflict conditions by queue source book. The audit rejects unknown candidate/book IDs, duplicates, unsupported recension text, absent provenance, hash mismatch when an archive is present, BSB reference mismatch, external browser dependencies, and empty complete text. Explicitly unavailable English is valid. Layer D is unchanged.
